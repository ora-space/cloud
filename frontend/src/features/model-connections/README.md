# model-connections：个人模型连接

## 职责

设置中当前用户私有的多连接、多模型表单与默认模型选择。连接元数据、版本和默认值由服务器负责；凭据只通过 Gateway 的写入/清除接口发送，页面没有读取密钥或导入 Pi 配置的能力。运行内切换模型与思考档位不属于本模块。

## 文件

| 文件 | 说明 |
| --- | --- |
| `api.ts` | 生成客户端适配、完整分页、版本化元数据/默认值、不会缓存原始请求错误的凭据边界 |
| `fields.tsx` | 有标签的元数据输入和有限选项选择 |
| `connection-form.tsx` | 两种协议、认证方式、可增删模型行的元数据草稿 |
| `credential-form.tsx` | 密码输入、发送前清空与安全结果文案 |
| `default-form.tsx` | 只提供已启用且有凭据的连接和其中模型 |
| `model-connections-page.tsx` | 列表、编辑、删除确认与页面组合 |
| `model-connections-page.test.tsx` | 通过生产生成客户端和 MSW 验证表单、请求、版本与凭据不进入缓存 |

## 依赖与不变量

依赖生成的 `api/me`、`features/spaces/api` 的幂等键、`lib` 的故障/分页适配、UI 原语；只由应用路由消费。下层不得反向依赖本模块。服务端状态保留在 TanStack Query，表单按资源版本重建编辑草稿；拒绝保存保留用户草稿。模型标识中的 `/` 原样发送。密钥输入不回填、不写入浏览器持久存储、不进入 TanStack mutation variables；提交时清空输入，HTTP 拒绝只保留白名单故障文案，避免 Axios 请求配置中的原始密钥被缓存。界面的禁用状态不替代服务器授权。

凭据 PUT 也必须带幂等键；该键通过共享适配器以连接/版本元数据生成，不保留密钥作为幂等变量。

## 测试

MSW 拦截真实 `/api/v1/me/model-*` 路径；密钥用测试时生成的无效合成值，不使用真实凭据。覆盖多模型与协议、默认选择、乐观版本、幂等删除、分页、加载失败以及请求过程中密码输入已清空且 mutation cache 不含密钥。
