# 会话分析

空间统一入口 `/w/:workspaceSlug/sessions`，首期只读取真实 Cloud Agent IssueRun。详情 `/sessions/agent/:issueId/:runId` 可返回原任务。聊天、工作流、小队、上传日志不在首期范围内。

| 文件                      | 职责                                                                  |
| ------------------------- | --------------------------------------------------------------------- |
| `api.ts`                  | 生成客户端边界、列表/项目分页、归档读取、手动 Thread 快照与向前分页。 |
| `metrics-api.ts` | 生成统计/模型请求客户端、独立授权缓存与受控游标分页。 |
| `session-list-page.tsx`   | 创建时间倒序列表、空态/错误态与详情导航。                             |
| `session-filters.tsx`     | 项目、Agent 标识、状态、浏览器本地时间范围筛选。                      |
| `session-detail-page.tsx` | 概览、模型请求、三泳道时间轴、工具统计、完整事件；刷新与权限错误。 |
| `session-metrics-panel.tsx` | 模型请求加载/失败/空态与展示模块接线，独立于归档可用性。 |
| `session-overview.tsx`    | 已加载记录计数、运行状态、固定模型与未知指标。                        |
| `presentation.ts`         | 状态、日期与安全错误文案。                                            |
| `sessions.test.tsx`       | HTTP 边界、分页/筛选、归档与快照、权限撤销、导航。                    |
| `session-metrics-page.test.tsx` | Gateway 统计分页、懒加载、归档独立性与权限失败缓存回归。 |

所有网络经生成的客户端和 Gateway Cookie；不扫描本机文件系统、不依赖静态验证数据。有 Revision 时仅采用校验后的 history，失败不自动冒充完整日志。尚未归档时读取 Thread 尾页，可手动加载更早页；此快照可能缺少超大记录正文。运行模型来自 Thread 的固定绑定；会话日志中的 Token/缓存/费用/API 请求耗时未知，不按文本条数推导。时间轴和完整记录委托 `session-timeline`，归一化委托 `session-data`。

“模型请求”按需读取独立统计契约，展示委托 `session-metrics`。汇总覆盖整个运行已记录的 HTTP 尝试，明细每页25条，按开始时间升序游标读取；不会补算采集前历史。普通归档/Thread故障不阻断请求统计，任何401/403均隐藏旧详情。统计或明细刷新失败不显示缓存成功内容。Gateway上游报告值与未来Agent上报用量必须分开，计数已知不代表流已完整结束。

列表游标绑定筛选缓存，过滤条件改变会重新从第一页开始。时间下界含、上界不含；日期提交转为 UTC。刷新后权限失败隐藏旧详情。生产 API 在每次请求核验当前成员关系。
