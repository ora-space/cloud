# agent-configurations：插件个人配置

[中文](README.md) | [English](README.en.md)

负责空间已选 Agent 版本的「我的配置」：非秘密选项、个人连接选择与显式修复。空间选择、运行启动及协议转换由各自模块负责。

| 文件 | 职责 |
| --- | --- |
| `api.ts` | 个人作用域查询、版本化写入与有界故障文案 |
| `draft.ts` | 类型化选项、默认值、编辑基线与移除字段核对 |
| `numbers.ts` | 响应数值原文与精确请求序列化，保留大整数和高精度小数 |
| `dialog.tsx` | 普通成员可用、打开时读取，并在写入后取回最新上下文交给编辑会话 |
| `editor-state.ts` | 编辑会话、冲突后显式核对、清除确认与凭据目标 |
| `editor.tsx` | 选项与独立连接表单的组合 |
| `options-form.tsx` / `setting-fields.tsx` | 类型化字段与修复/清除操作 |
| `reconcile.tsx` | 最新值比较、保留草稿或采用服务器值 |
| `connections.tsx` | 匹配协议的模型选择、内联创建与按所选连接展示的凭据表单 |
| `dialog.test.tsx` / `*.test.*` / `test-fixtures.ts` | 生产对话框、选项与 HTTP 表单行为测试，含合成上下文 |

依赖生成客户端、`spaces`、`model-connections`、`lib` 与 UI 原语；由 `plugins` 消费，下层不得反向依赖。连接与凭据沿用个人连接库；OpenCode 默认模型沿用全局默认选择，不在插件配置中复制引用，其凭据入口跟随默认草稿所选连接。

编辑基线只在成功写入或用户明确核对时推进。写入只把选项基线推进到写响应确认的版本：随后读取的仍是该版本且发布上下文未变时原地采用，不重建编辑会话，因此独立的默认模型草稿及其 CAS 版本不会无提示回退；读到其他编辑器的后续写入或选用变化时保留草稿并要求显式核对，不把新版本号与旧草稿自动拼接。背景刷新与 409 保留草稿；声明变化必须确认修复，不自动迁移或丢弃未知字段。清除个人选项不删除连接。API Key 只经过复用的写入边界，不进入配置请求、查询/变更缓存或持久存储。所有表单互为同级。

测试使用真实生成客户端和 MSW，覆盖类型、修复、版本冲突、内联连接与凭据隔离；`dialog.test.tsx` 用生产对话框验证保存和清除只推进选项基线、保存后读到并发写入时要求核对，`plugins` 测试覆盖成员入口的延迟读取。
