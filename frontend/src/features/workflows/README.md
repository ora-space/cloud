# 工作流页面与契约接线

本模块组合工作流列表、编辑与运行页面，维护 API 查询和功能级翻译；图的纯规则属于 `runtime/`，画布与检查器属于 `editor/`，运行展示属于 `run/`。

| 文件                          | 职责                           |
| ----------------------------- | ------------------------------ |
| `api.ts`、`error-messages.ts` | 查询、变更和稳定错误映射       |
| `*-page.tsx`                  | 路由页面组合                   |
| `*translations.ts`            | 功能文案与发布门禁的本地化指导 |

依赖生成 API、基础组件、身份与空间上下文；应用路由消费本模块。发布错误按稳定门禁码显示具体、可操作的原因，不展示原始服务端消息。测试通过查询边界和页面行为验证契约，不能用通用提示掩盖已知门禁原因。
