# 模型请求统计

展示 Cloud Gateway 已记录的 HTTP 尝试及上游报告的用量，独立于会话归档和原三泳道时间轴；不请求网络、不读取本地日志、不估算 Token 或费用。

| 文件 | 职责 |
| --- | --- |
| `index.ts` / `session-metrics.tsx` | 公共展示入口、旧会话空态与受控分页。 |
| `metric-summary.tsx` | 全部已记录请求的状态、独立 Token 字段、时长和覆盖率。 |
| `metric-values.ts` | 字段标签、计量口径、Decode 速率推导和保留未知/真实零的格式化。 |
| `request-trend.tsx` | 当前页每请求单字段趋势；相邻已知值实线连接，跨缺失观测用带说明的虚线。 |
| `request-table.tsx` | 请求标识、协议、状态、结束观测、时长、平均 Decode 速率与上游计数。 |
| `session-metrics.test.tsx` | 合成样本验证覆盖率、未知值、零、趋势、分页及空态。 |

仅依赖生成 API 类型和 UI 基础组件；`sessions` 负责授权、网络、错误与分页状态后调用本模块。汇总覆盖整个运行中已记录的请求，趋势和明细只覆盖当前页；两者不可混淆。HTTP 重试分别计数，不把文本条数当请求数。不把缓存重复加到输入，不把 reasoning 再加到输出，上游总 Token 保持独立。Gateway 观测时长不是模型内部耗时，首次有效输出忽略心跳和空片段。所有未知显示“未知”，已知 `0` 保留，部分覆盖合计仅来自已知样本；零条观测不代表零历史消耗。未来 Agent 上报用量必须单列，不并入本来源。

测试经公共组件进行真实表单交互；使用合成数据，不复制真实请求或个人会话内容。

趋势保留全部请求的横轴位置与分页编号。圆点只代表已报告值，真实零在数值基线上；未报告值用轴下独立区域的 `×` 标记，提示中展示已有请求状态，绝不补零。虚线仅连接两端已知观测，提示跨过的未报告请求数量，不插值、不累计、不向首尾未知区间延伸。全未知页仍展示请求位置和缺失标记，不展示虚构的数值刻度。回归覆盖连续缺失、首尾缺失、零、孤立观测、全未知、字段切换及分页编号。

`started` 显示为“待完成观测”，不认定请求仍然活跃：请求可能在进行，也可能结束后未采集到完成记录。即使某字段的已知数量等于请求总数，服务端标记 `partial` 时仍展示部分数据或未终结快照。

平均 Decode 速率列以 `outputTokens × 1000 / (durationMs - firstOutputMs)` 展示 Token/s，仅适用于成功结束、已观测协议结束且用量完整的流式请求。它是首次有效输出到请求结束的网关观测估算，包含网络和协议收尾时间，不代表模型内部纯 decode 性能。非流式、未完成/失败/取消/中断、部分用量、缺失或非法计数/耗时、非正时间差显示“未知”；真实零保留，正数不足 0.1 时显示 `< 0.1`，其他数值最多一位小数。输出只使用供应商的 output，不叠加 reasoning。回归通过公共组件覆盖两种协议、计算口径、格式化及上述未知边界。
